# 아트 비행 · Art Flight (Gallery 2026)

Gallery 2026 전시의 일환으로 제작된 인터랙티브 웹 아케이드 미니게임입니다.
종이비행기를 조종해 떨어지는 물감과 액자를 맞추고, 캔버스 위에 나만의 추상화를 완성해 보세요.

## 주요 특징
- **캔버스 스플래터 연출:** 물감이 터질 때마다 배경에 은은한 파스텔 얼룩이 남아 매 판 새로운 추상화가 완성됩니다.
- **콤보 & 파워업:** 연속 명중 시 콤보 배율 보너스 점수가 적용되며, 특수 오브젝트 파괴 시 방어막(Shield), 3연발(Triple Shot), 생명 회복 아이템이 드롭됩니다.
- **Web Audio 합성 사운드:** 외부 오디오 리소스 없이 브라우저 자체 신시사이저로 갤러리 분위기에 맞는 효과음을 생성합니다.
